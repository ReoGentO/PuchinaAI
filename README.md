# Пучина-AI (PuchinaAI)

> **Система предиктивного мониторинга и прогнозирования риска деформаций дорожного покрытия на основе анализа циклов замерзания-оттаивания.**

Исследовательский комплекс и программная реализация гибридной нейросетевой модели и ML-бейзлайнов для прогнозирования риска морозного пучения дорожного полотна с горизонтами упреждения **30, 60 и 90 дней**.

---

## 📌 Ключевые возможности

1. **Инженерия физических признаков пучинообразования:**
   - $F_{cross}$ — суммарное количество переходов температуры через 0 °C (циклы замерзания-оттаивания).
   - $F_{cross\_decade}$ — декадное число переходов через 0 °C для порога тревоги.
   - $T_{sum}$ — кумулятивная сумма отрицательных температур (градусо-дни промерзания).
   - $Snow_{avg}, Snow_{max}$ — характеристики теплоизолирующего снежного покрова.
   - Динамика влажности грунта и осадков.
2. **Модели машинного обучения и нейросети:**
   - **Random Forest Classifier** (взвешенный по классам бейзлайн, $F_1 = 0.727$, Recall = 88.9% для аварийного класса).
   - **XGBoost Classifier** (градиентный бустинг, Recall = 88.9%, Weighted $F_1 = 0.938$).
   - **Гибридная нейросеть 1D-CNN + LSTM/GRU** (Keras/TensorFlow, многомасштабные свертки с ядрами 3, 5, 7 для захвата резких градиентов + рекуррентный блок накопления эффекта).
3. **Физическая интерпретация и критерий тревоги (XAI):**
   - Расчет матрицы SHAP-значений (`TreeExplainer`) с построением Beeswarm и Bar графиков.
   - Калибровочная кривая порога тревоги: при $F_{cross\_decade} \ge 6$ модельный риск деформаций превышает **67.5%** (фактическая доля: **66.7%**), а при $\ge 7$ достигает **100%**.
   - Построение сезонной динамики риска деформаций во времени.
4. **Тесты физической правдоподобности:**
   - Комплекс из 6 тестов (летний контроль, чувствительность к влажности, суровость промерзания, устойчивость к шумам датчиков, аксиомы вероятностей Колмогорова, временные профили CNN+LSTM).

## 📊 Классификация состояний дорожного полотна

| Класс | Наименование | Величина пучения $H(t)$ | Описание |
| :---: | :---: | :---: | :--- |
| **0** | **Норма** | $H < 10$ мм | Безопасная эксплуатация дороги |
| **1** | **Преддефектное** | $10 \le H \le 30$ мм | Локальные вспучивания, микротрещины, разуплотнение полотна |
| **2** | **Аварийное** | $H > 30$ мм | Критическая пучина, угроза разрушения полотна и ДТП |

## 🚀 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/ReoGentO/PuchinaAI.git
cd PuchinaAI
```

### 2. Создание виртуального окружения и установка зависимостей
```bash
python -m venv .venv
# Активация на Windows PowerShell:
.\.venv\Scripts\Activate.ps1

pip install -r requirements.txt
```

### 3. Запуск полного исследовательского конвейера
Обучение всех моделей, оценка на 30/60/90 дней, генерация таблиц и графиков:
```bash
python main.py --horizon 30 --epochs 25
```

### 4. Автономный предиктивный CLI-инструмент для дорожных служб
Прогноз состояния дороги на дату с горизонтом упреждения и рекомендациями:
```bash
# Прогноз на 30 дней вперед от текущей даты по модели XGBoost
python predict.py --horizon 30 --model xgb --date 2024-03-15

# Прогноз по гибридной нейросети CNN+LSTM
python predict.py --horizon 30 --model cnn_lstm --date 2024-03-15
```

### 5. Запуск тестов
```bash
python -m unittest discover -s tests
python tests/test_plausibility.py
```
