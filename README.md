# Пучина-AI (PuchinaAI)

> **Система предиктивного мониторинга и прогнозирования риска деформаций дорожного покрытия на основе анализа циклов замерзания-оттаивания и инженерных сетей.**

Исследовательский комплекс и программное решение для заблаговременного (горизонты **30, 60 и 90 суток**) выявления зон морозного пучения и криогенного разрушения автомобильных дорог в криолитозоне и районах глубокого сезонного промерзания грунтов.

---

## 📌 Ключевые возможности и физическая концепция

Система построена на сочетании физических закономерностей механики мерзлых грунтов, теории термомеханической усталости дорожных одежд и передовых методов объяснимого искусственного интеллекта (XAI):

1. **Строгая иерархия физических факторов (XAI / SHAP)**:
   - **$F_{\text{cross}}$ (Ранг #1 по значимости)** — активный динамический криогенный индекс знакопеременных циклов замерзания-оттаивания ($T = 0\ ^\circ\text{C}$). Учитывает острые фазовые импульсы в декадном и месячном скользящих окнах в сочетании с пороговым сезонным накоплением.
   - **`cumulative_cycles` (Ранг #2 по значимости)** — кумулятивная сезонная усталость и глубина криогенной деструкции полотна (накопленный счетчик циклов перехода через 0 °C с начала зимнего периода).
   - **`moisture_avg` (Ранг #3)** — объемная влажность грунта рабочего слоя земляного полотна (определяет объем льдовыделения и сегрегации влаги).
   - **`snow_avg` и `t_sum` (Ранги #4–5)** — средняя мощность теплоизолирующего снежного покрова и градусо-дни холода (сумма отрицательных температур, глубина промерзания).
   - **`t_avg` (Ранг #6)** — средняя фоновая температура воздуха.
   - **`is_heatpipe` (Ранг #7)** — **учет инженерных сетей и систем термостабилизации грунтов**: бинарный учет наличия сезонноохлаждающих устройств (СОУ / термосифонов) на опытных участках (ОП) по сравнению с контрольными (КП).

2. **Модели машинного обучения и гибридные нейросети**:
   - **XGBoost Classifier**: градиентный бустинг со сбалансированным взвешиванием классов и калибровкой выборки признаков.
   - **Random Forest Classifier**: ансамбль решающих деревьев с защитой от переобучения.
   - **Hybrid CNN + BiLSTM + ZeroCrossingAttention**: 8-канальная глубокая нейросеть (вход `(Batch, 45, 8)`), объединяющая многомасштабные 1D-свертки (ядра 3, 5, 7) для локальных градиентов, двунаправленный BiLSTM для сезонного контекста и кастомный механизм внимания `ZeroCrossingAttention` (фокусировка весов на сутках перехода через 0 °C).

3. **Инженерный критерий тревоги и оперативное реагирование**:
   - Автоматический расчет пороговых кривых зависимости риска деформации от интенсивности знакопеременных циклов.
   - Практическая классификация состояний полотна по ГОСТ Р 50597-2017 с выдачей регламентных указаний дорожно-эксплуатационным службам (ДЭС).

4. **Физическая валидация (Sanity Checks)**:
   - Пакет из 6 автоматических тестов на соблюдение законов геотехники, теории вероятностей Колмогорова и устойчивости к шумам датчиков телеметрии.

## 📊 Классификация состояний дорожного полотна

В соответствии с требованиями ГОСТ Р 50597-2017 и ОДМ 218.3.107-2019 принята трехклассовая модель риска:

| Класс $Y$ | Наименование состояния | Величина пучения / колейности | Регламентные действия эксплуатирующих служб |
| :---: | :--- | :---: | :--- |
| **0** | **Норма** | $< 1.5$ см | Штатный режим движения, регулярный мониторинг. Трещины $< 1.5$ м. |
| **1** | **Преддефектное состояние** | $1.5 \le H < 3.0$ см | Внимание: локальное разуплотнение полотна. Назначение внеочередного визуально-инструментального осмотра. |
| **2** | **АВАРИЯ / ТРЕВОГА** | $\ge 3.0$ см | **Критический риск разрушения**. Введение ограничений скорости/нагрузки на ось, подготовка ямочного/восстановительного ремонта. |

## 💻 Эксплуатация: оперативный CLI-модуль (`predict.py`)

Модуль предназначен для ежедневного использования инженерами дорожных служб.

### Прогноз на заданную дату с горизонтом 30 дней:
```bash
# Прогноз по модели XGBoost
python predict.py --model xgboost --date 2026-04-15

# Прогноз по модели Random Forest
python predict.py --model rf --date 2026-04-15

# Прогноз по гибридной нейросети CNN+BiLSTM+Attention
python predict.py --model hybrid_nn --date 2026-04-15
```

## 🔬 Запуск сквозного научного конвейера (`main.py`)

Выполняет полный цикл: генерация/загрузка данных, расчет 7 физических признаков, обучение 3 моделей для горизонтов 30, 60 и 90 суток, расчет SHAP-значений, построение матриц ошибок и калибровка порога тревоги:

```bash
python main.py --data data/processed/dataset_defect_1_labelled.csv --horizon 30 --epochs 30
```

## 🧪 Тестирование и верификация

### Запуск модульных тестов конвейера:
```bash
python -m unittest tests/test_pipeline.py
```
*Проверяет корректность расчета знакопеременных циклов, сборку 8-канальных 3D-тензоров и архитектуру Keras-модели.*

### Запуск тестов физической правдоподобности (Sanity Checks):
```bash
python -m unittest tests/test_plausibility.py
```
*Проверяет:*
1. Отсутствие аварийности в начале сезона без циклов ($F_{\text{cross}} = 0$).
2. Статистическую чувствительность моделей к влажности грунта рабочего слоя.
3. Монотонный рост риска аварийности при увеличении числа знакопеременных циклов 0 °C.
4. Устойчивость предсказаний к шумам датчиков телеметрии.
5. Строгое соблюдение аксиом теории вероятностей Колмогорова ($\sum P_i = 1.0, P_i \ge 0$).
6. Адекватность отклика нейросети CNN+BiLSTM на сезонные временные последовательности.

- **ОДМ 218.3.107-2019** «Методические рекомендации по оценке пучинистости грунтов земляного полотна».
- **СП 25.13330.2020** «Основания и фундаменты на вечномерзлых грунтах».
